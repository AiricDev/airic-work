# Methods 行为验收

范围：Methods.latest/read/search/history/status/sync、受管远端仓库或直接复用本地 Git 仓库、固定 SHA 快照与可重建 FTS5 索引。
不实现 Agent 装配、Git Review、发布或 OM 编辑。2026-10-30 确认：本地使用配置分支的已提交版本，只显式同步，本轮不支持无 Git 的普通目录。

| 场景 | Given / When | Then |
| --- | --- | --- |
| M01 | 受管来源分支上有新提交，调用 latest | 实际 clone/fetch 并确认来源分支，固定真实 SHA 和可读 Root；版本配置来自可信宿主 |
| M02 | 受管来源不可达，或任一来源分支不存在/确认时已变化 | 明确阻塞，不把缓存当最新；旧快照仍可离线读取 |
| M03 | 同来源提交/分支变化、来源切换或重开 adapter | 每次读取与检索限定来源/SHA；原快照和其内容不变 |
| M04 | Root 不存在、是链接或不是可读 UTF-8 文本 | 不返回可启动的 Method，不伪造 Root |
| M05 | 仓库含 .ome、符号链接、子模块、越级路径 | 不导出作者目录、链接或子模块；读取不能越出指定快照 |
| M06 | 搜索中文、短词、路径、正文及含 SQL/FTS 标点的字面查询 | FTS5 trigram 或短查询 LIKE 回退，稳定路径/片段，不混版本、不把标点当查询语言 |
| M07 | 索引删除或重建中失败 | 从固定快照重建；索引替换与标记同事务；不更改 Git 或业务控制记录 |
| M08 | 同来源并发同步或相同快照同时发布 | 完整目录原子发布；失败只清理自身 staging，不覆盖旧快照；Git 锁竞争可明确阻塞后重试 |
| M09 | 查询来源历史 | 来自真实 Git，限量及覆盖限制明确，不伪造完整历史、不触发发布或业务动作 |
| M10 | 非允许来源、非法路径/版本、资源上限或 Git 进程失败 | 拒绝且不泄漏命令、认证或宿主路径，不截断成貌似完整结果 |
| M11 | Git 确认后配置版本发生变化，再提交执行准备 | 既有 Store CAS 拒绝；不固定过期 Method、不新增 Start Input，也不激活 Agent |
| M12 | 两个独立进程首次从同一离线快照建立索引 | 共享连接层有界协调 WAL 初始化，完整索引事务提交；双方得到相同检索结果 |
| M13 | 来源为本地 Git 仓库目录 | 直接读取配置分支提交，不 clone、不 fetch、不修改工作区；未提交及未跟踪文件不进入运行快照 |
| M14 | 本地仓库没有 remote | 仍可准备运行、浏览、搜索及读本地历史；status 明确同步禁用、原因和提示，sync 在服务端拒绝 |
| M15 | 本地仓库有 remote，查询状态 | 优先显式配置、分支 upstream、origin、唯一 remote；多个候选无法确定时禁用并提示，不能随意挑一个 |
| M16 | 本地 remote 不可达，未请求同步 | 本地已提交版本仍可使用；只有显式 sync 失败，不静默切换来源 |
| M17 | 请求同步且远端可快进、工作区干净、配置分支已检出 | fetch 后安全快进；后续执行使用新提交，旧快照保持不变 |
| M18 | 同步时已跟踪文件/暂存区有修改、分支分叉或当前检出其他分支 | 明确拒绝，不 reset、stash、强制更新或自动 checkout；本地文件/提交保留，未跟踪文件碰撞由 Git 拒绝 |
| M19 | 目录不是仓库根、没有提交或配置分支缺失 | 明确阻塞，不隐式 git init、不退回父目录仓库或缓存 |
| M20 | remote 使用不允许的协议或含凭据 | 禁用同步并给脱敏提示，本地运行仍可用，不执行任意 remote helper |

来源映射、资源界限及声明的 Runtime/Skill 版本由可信宿主显式配置。
SHA-1/SHA-256 对象格式均有真实仓库覆盖。历史返回明确的分支覆盖范围，不声称包含 tag-only 历史。
本批只验证本地 Git 测试仓库，不把它等同于 HTTPS/SSH 或 Agent 部署验证。
