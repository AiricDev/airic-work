# Identity 与本机管理员命令行为验收

2026-10-30 确认：固定可信 HTTPS 用户信息接口，GET + Bearer token；管理员通过本机命令显式提升已有用户，不自动提升首个用户。

| 场景 | Given / When | Then |
| --- | --- | --- |
| I01 | 可信接口认证成功，返回稳定 ID 与显示名 | 返回配置的 issuer 与映射字段，不接受正文里的权限、issuer 或客户端自选身份 |
| I02 | 同一身份再次认证或并发首次认证 | 经 AccountUseCases/Store 复用同一 User，保留本地名称、资格、管理员权限 |
| I03 | token 空、含控制字符或超过配置界限 | 联网前拒绝；不把 token 放入 URL、错误或日志 |
| I04 | 上游 401/403、超时、TLS 失败、网络故障或非成功状态 | 拒绝，不创建用户；不缓存成功认证以绕过后续失效，不自动重试 |
| I05 | 上游重定向 | 拒绝，不把 Bearer token 发送到新地址 |
| I06 | 上游 JSON/字段/UTF-8/类型无效，正文过大或不完整 | 明确阻塞，不用 email/name/空值代替稳定 ID，不传播原始响应 |
| I07 | 已停用用户再次通过外部认证 | 保持停用并拒绝，不恢复使用资格 |
| A01 | 本机操作员指定已有启用用户 ID | 原子只提升 admin 与递增版本，其余资料不变；重复执行幂等 |
| A02 | 用户不存在或已停用 | 拒绝，不创建/启用用户 |
| A03 | 数据库不存在、是链接、版本未知或迁移摘要不符 | 拒绝，不创建空库、不应用迁移或初始化设置 |
| A04 | 多进程同时提升同一用户 | 仅一次有效版本变更，无丢失资料；失败不留下部分权限更新 |
| A05 | 普通 HTTP/只读 MCP 调用 | 无本机提升入口；只有持有数据库操作系统权限的显式 CLI 可调用 |

本批不实现 token 托管/续期、JWT/OIDC 登录或后台 MCP 凭据交付。真实集成方须承诺：该用户信息接口仅在 token 当前有效时返回 200；不是 RFC 7662 introspection 接口。
