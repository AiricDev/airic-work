# Case Study（案例研究）

Case Study 是 OME 的研究方法，用于从具体案例发现或修正判断知识。Create 可用它发现 Decision，Improve 可用它检查已有判据、依赖和例外。Decision Episode、既有成果及参与者的解释可作为研究材料。研究笔记与验证材料沿用宿主的作者侧工作区。

## 研究一个有区分力的判断

1. **选案例和问题。** 先确定想理解的判断，例如为什么接受、拒绝、选择某个方案或停止调查。选择有可追溯来源的具体案例，明确其版本和研究范围。一个案例可以支持多个判断，各自说明研究问题。
2. **重建当时的情境。** 追溯目标、约束、当时可见的证据、可选行动、实际判断及已知后果。分别归因原始记录、参与者的事后解释和 Agent 推断。成果可以帮助定位判断，未记录的过程和原始理由保留未知。
3. **用差别提取尺度。** Agent 先提出有依据的候选解释，请熟悉案例的人纠正。追问只改变一个关键条件时，判断或后续行动是否会变，必要时对照相邻案例。区分正式要求、专业裁量和个案例外，提取证据何时够用、什么缺陷必须处理、什么变化需要继续调查或升级。保留分歧和待验证的解释。
4. **检验能否用于未来判断。** 先写清适用条件、失效条件和预期，再检查执行者能否仅凭作判断前可获得的输入运用它。按[行为验证](evaluation-learning.md)使用未参与提取的案例、独立复核或可核验结果。分别记录同案回读、反事实讨论和独立验证所支持的范围。

## 让研究结果进入合适的知识对象

新发现的判断问题形成 Decision 候选。证据要求、接受尺度或例外的变化进入已有 Decision 的候选修订。对特定判断有解释价值的案例，按[对象契约](artifact-contracts.md)保留来源、用途和迁移边界，经适当验证及既有审阅采用后成为 Precedent。来源只支持历史事实时，记录为有限参考或来源材料。仍无法解释且影响未来判断的差异，保留为待验证假设或 Knowledge Gap。
